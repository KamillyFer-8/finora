# Gestão do projeto

O Finora usa entregas incrementais por sprint. Novas mudanças devem partir de uma issue,
usar uma branch curta (`feature/`, `fix/` ou `docs/`), commits convencionais e pull request.

## Quadro sugerido no GitHub Projects

- Backlog: demanda descrita e priorizada;
- Ready: critérios de aceite definidos;
- In progress: desenvolvimento ativo;
- Review: CI aprovado e revisão pendente;
- Done: merge realizado e documentação atualizada.

As issues e pull requests possuem templates no repositório. O quadro remoto pode ser criado
quando o repositório for publicado no GitHub, sem alterar a arquitetura da aplicação.
