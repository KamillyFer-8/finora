# Dependências

## Frontend

- Next.js, React e TypeScript: aplicação e tipagem.
- Tailwind CSS: styling e design tokens.
- Redux Toolkit e React Redux: preferências e estado global de UI.
- TanStack Query: server state.
- Axios: cliente REST.
- React Hook Form e Zod: formulários e validação (instalados na fundação, usados a partir da Sprint 2/3).
- Recharts: gráficos (usado na Sprint 6).
- Jest, Testing Library e MSW: testes de unidade/integração.
- Playwright: E2E (configurado e ampliado na Sprint 7).

## Backend

- FastAPI e Uvicorn: API ASGI.
- Pydantic Settings: configuração validada.
- SQLAlchemy, Alembic e psycopg: persistência PostgreSQL e migrations.
- Pytest e HTTPX: testes.
- Ruff e mypy: lint, formatação e tipos.

Bibliotecas de JWT e hash são adicionadas apenas nas sprints que as utilizam. O armazenamento de anexos usa APIs nativas do Python atrás de uma abstração própria.
